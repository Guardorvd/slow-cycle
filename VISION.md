# Slow Cycle — краткое продуктовое направление

STATUS: CURRENT

Scope: производное резюме [Target Blueprint](docs/TARGET_GAME_BLUEPRINT.md); самостоятельных требований не вводит. Стратегия — [Master](docs/MASTER_IMPLEMENTATION_PLAN.md); [навигация](docs/README.md); [прежний manifesto](docs/history/VISION_PRE_D0.md).

Slow Cycle создаёт место, по которому хочется путешествовать на велосипеде. Игрок садится на велосипед и едет куда хочет: чувствует движение, видит природные возможности, выбирает маршрут, обнаруживает новое и меняет первоначальный план.

```text
SEE → WANT → CHOOSE → RIDE → DISCOVER → REWARD
                     ↑                   ↓
                     └── CHANGE PLAN ← SEE SOMETHING ELSE
```

Целевой баланс Blueprint: 55% удовольствие от езды, 45% атмосфера/созерцание/исследование. Мир существует до дорог: идентичность региона → geography/hydrology/biomes → маршруты → local geometry → final surface/environment. Осмысленная структура + noise; убедительная природа + романтизированная композиция.

Свобода — backbone/secondary/singletrack/technical пути, loops/merges/cross-connections и проезжаемые луга/редкий лес. Границы преимущественно природные: slope, cliffs, dense forest, water. Landmarks, vistas и human traces вызывают любопытство без карты, заполненной заданиями.

Первый Mountain River Valley slice — 20–30 минут содержательной поездки без debug UI, реальные решения о направлении, хотя бы одно изменение плана из-за увиденного, off-road, alternative loop и сильный reveal. Человек оценивает удовольствие/свободу/географию/красоту; automated PASS не заменяет это.

Зрелый region experience 40–70 минут и region continuation — долгосрочная цель, не текущая готовность. Существующий велосипед остаётся аватаром; walking, races, survival, inventory, XP/quests/upgrades и unrelated systems откладываются по anti-scope Blueprint/Master.

D0 меняет authority документации. Последующие D1/Q/R-фазы выполняются по отдельным approved plans. Историческая бесконечная road ribbon не является обязательной архитектурой новой игры.
