# Slow Cycle — Road & World Generation Specification (v2.0)

## 1. Контракт данных: `RoadPathData`
Центральным источником правды для дороги является структура `RoadPathData`.
Она отделяет логику маршрута от рендеринга и физики:
```gdscript
class_name RoadPathData
extends RefCounted

var global_points: PackedVector3Array        # Опорные точки осевой линии
var tangents: PackedVector3Array             # Векторы направления
var normals: PackedVector3Array              # Векторы нормали
var cumulative_distances: PackedFloat32Array # Дистанция s вдоль дуги (для точного Recovery)
var slopes: PackedFloat32Array               # Уклон в градусах
var curvatures: PackedFloat32Array           # Кривизна (1 / Radius)
var segment_type: int                        # STRAIGHT, GENTLE_ENTRY, FULL_CURVE, EXIT, DESCENT
```

---

## 2. Ритм маршрута и переходные спирали (Easement Curves)
- **Ритм дороги**: Планировщик `road_logic.gd` формирует чередующиеся последовательности участков:
  `[Прямая]` $\rightarrow$ `[Плавный вход в поворот]` $\rightarrow$ `[Вираж]` $\rightarrow$ `[Плавный выход]` $\rightarrow$ `[Спуск накатом]` $\rightarrow$ `[Поляна]`.
- **Сглаживание кривизны**: Поворот не начинается мгновенно. Кривизна нарастает постепенно (аналог переходной кривой / клотоиды), предотвращая рывки руля.
- **Валидатор до меша**: Каждый сегмент проходит проверку на лимиты уклонов ($[-6.5^\circ; +5.5^\circ]$) и радиуса ($\ge 38\text{м}$) до того, как строится геометрия. Если лимиты превышены — сегмент перегенерируется с безопасными параметрами.

---

## 3. Толерантность стыков чанков (Вместо абстрактного "идеала")
Геометрические инварианты на границе между чанком $N$ и $N+1$:
- Разрыв координат: $\Delta p < 0.001\text{ м}$.
- Разница направления касательных: $\Delta \theta < 0.2^\circ$.
- Перепад уклона: $\Delta \alpha < 0.1^\circ$.
- Меш и коллизия строятся из одного массива вертексов.

---

## 4. Полосовой террейн и двухслойная физика
- **Ширина дороги**: $4.0\text{ м}$ утрамбованного гравия с колеями. Назначена на **Layer 2 (`Road`)**.
- **Обочины**: по $1.0\text{ м}$ утрамбованной земли с каждой стороны.
- **Полосовой рельеф**: по $20\text{ м}$ холмов с шумом высот с каждой стороны. Назначен на **Layer 3 (`Grass`)**.
- **Трение**:
  - На Layer 2 (`Road`): базовое сопротивление качению ($0.35$).
  - На Layer 3 (`Grass`): повышенное сопротивление качению ($1.45$), настраиваемое через параметры.

---

## 5. Дистанционный стример чанков
- Стриминг привязан к дистанции до игрока, а не к номеру чанка:
  - `AHEAD_DISTANCE = 350\text{ м}`.
  - `BEHIND_DISTANCE = 60\text{ м}`.
- Пройденные чанки удаляются через `queue_free()`.
- Сетки деревьев (`PineMesh`, `BirchMesh`, `GrassMesh`) хранятся в единственном экземпляре в `WorldManager` (Shared Resources), а чанк хранит только легковесные инстансы `MultiMeshInstance3D`.

---

## 6. Recovery System (Клавиша R)
- `BicycleController` запрашивает восстановление у `WorldManager`.
- `WorldManager` находит текущую позицию на `RoadPathData`, отступает $20\text{ м}$ назад **вдоль длины дуги дороги ($s$)**, а не по прямой.
- Возвращает позицию по центру дороги с правильным азимутом и уклоном.
- Экран плавно затемняется на $0.25\text{ с}$, байк переносится, скорость выставляется в $3\text{ м/с}$, экран осветляется. Застрять невозможно.
