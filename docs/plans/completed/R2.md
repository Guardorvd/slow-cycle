# R2 — Terrain Tile Contract — ExecPlan v1.0

## 1. Goal

Turn R1 macro geography into a trustworthy **world-space terrain query contract** (`TerrainField`: height, gradient, normal) and a separate **tile renderer** (`TerrainTileRenderer`) that builds tiles only through that contract, so that neighbouring tiles share edges by construction — each tile built independently, with no shared cache — and later phases (R3 hydrology, R4 biome/rideability, R5 routes, R7 FinalSurface) have one stable surface to depend on.

Product order is unchanged: WORLD FIRST → ROUTE SECOND → ROAD THIRD. R2 changes no geography.

## 2. Observed current state (read 2026-10-06)

| Item | Fact |
|---|---|
| Height math | `MacroTerrainEvaluator` (static, RefCounted): `evaluate_[structure_]elevation_m(plan, local_x, local_z)` and `sample_grid(...)`, **region-local** closed square `[0,4096]²`. Builds a derived `Context` from `plan.get_data()` (deep copy) **on every point call** (~0.7 ms, R1 D6); the grid builds it once with 256 m spatial buckets. ## 3. Target behaviour

```text
RegionGenerator.build(world_seed, coordinate) -> RegionPlan            (R0/R1, unchanged)
  -> TerrainField.create(region_plan) -> {is_valid, field, reason_code} (R2: sole public base-terrain query surface)
       internal kernel: MacroTerrainEvaluator (prepared context, R1 math, unchanged numerics)
  -> TerrainTileRenderer.tile_arrays / tile_mesh(field, tile_x, tile_z)   (R2: arrays + ArrayMesh only)
  -> region_preview.gd                                                    (composition: nodes, material, camera)
```

**Authoritative height.** `TerrainField` owns base-terrain height/gradient/normal in world space. Its height is, by definition, R1's final elevation (`structure + bounded noise`) evaluated at `world − region_min`. The evaluator becomes the field's private kernel: new consumers (renderer, preview, R3+) depend on `TerrainField`, never on the evaluator. R7 `FinalSurface` will later compose this base terrain with deformations; until then `TerrainField` is the terrain truth.

**Lattice.** One world-anchored sample lattice: `LATTICE_STEP_M = 16`, point `(i, j)` ↔ world `(16·i, 16·j)` with int64 `i, j`. Tiles are `TILE_CELLS = 32` cells = 512 m; a region holds exactly 8×8 tiles. Vertex world coordinates are always computed from integer lattice indices — never accumulated floats or tile-relative offsets.

**Gradient and normal (single definition).** `gradient(x,z) = ((H(x₁,z) − H(x₀,z)) / (x₁ − x₀), (H(x,z₁) − H(x,z₀)) / (z₁ − z₀))` with `x₀ = max(min_x, x − 16)`, `x₁ = min(max_x, x + 16)` (same for z): central ±16 m inside, one-sided at the region edge, never a zero span. `normal = Vector3(−g.x, 1, −g.y).normalized()` — always finite, unit, `y > 0`. The 16 m half-step is a **field constant** (macro "terrain-scale slope"), independent of any mesh resolution; it equals R1's accepted preview normals exactly, so R2 is visually behaviour-preserving.

**Seams absent by construction.** A shared edge vertex is the same lattice point → the same field query → bit-identical height, gradient and normal, regardless of which tile asks first, in which order, or from which field instance. The renderer never reads a neighbour's data.

**Exclusions:** hydrology, biomes, rideability, routes/roads, vegetation, FinalSurface/deformation, streaming, LOD, caching beyond the per-field prepared context, threading, collision, cross-region continuity, main-game/WorldManager wiring, player/camera/physics, any geography change.

## 6. Public contracts

`TerrainField` (`scripts/world/region/terrain_field.gd`, RefCounted, `SCHEMA_TAG = "slow_cycle.terrain_field/1"`, `LATTICE_STEP_M = 16`, `GRADIENT_HALF_STEP_M = 16.0`):

| Call | Result |
|---|---|
| `static create(region_plan) -> {is_valid, field, reason_code}` | `ERR_TERRAIN_PLAN_MISSING` (null / no macro), `ERR_TERRAIN_PLAN_INVALID` (`region_plan.validate()` not valid). No fallback. |
| `sample_height(x, z) -> {is_valid, height_m, reason_code}` | world metres; NaN on failure |
| `sample_gradient(x, z) -> {is_valid, gradient: Vector2(dh/dx, dh/dz), reason_code}` | definition §3 |

| `sample_lattice(i0, j0, count_x, count_z) -> {is_valid, heights_m: PackedFloat64Array, gradients: PackedVector2Array, normals: PackedVector3Array, reason_code}` | row-major (z outer); bit-identical to the point calls at the same lattice points |
| `get_bounds_m() -> {min_x, min_z, max_x, max_z}` (int) , `get_region_signature()` | identity/bounds |

Domain: closed world square `[min, max]²` of the plan's region. Reasons in check order: `ERR_TERRAIN_NONFINITE_INPUT`, `ERR_TERRAIN_OUT_OF_DOMAIN` (point outside, or lattice block not fully inside — integer arithmetic, which also bounds a block to ≤ 257² samples), `ERR_TERRAIN_GRID_SHAPE` (count ≤ 0).

`TerrainTileRenderer` (`scripts/world/region/terrain_tile_renderer.gd`, RefCounted, static, `TILE_CELLS = 32`, `TILE_SIZE_M = 512`):

- `tile_arrays(field, tile_x: int, tile_z: int) -> {is_valid, arrays (Mesh.ARRAY_MAX layout: VERTEX tile-local, NORMAL, INDEX), origin_x_m: int, origin_z_m: int, reason_code}` — 33² vertices, 6144 indices, clockwise from +Y; one `sample_lattice` call; int64 tile indices (not `Vector2i`).
- `tile_mesh(field, tile_x, tile_z) -> {is_valid, mesh: ArrayMesh, origin_x_m, origin_z_m, reason_code}`.
- Reasons: `ERR_TILE_FIELD_MISSING`; otherwise the field's reason is passed through unchanged.

Compatibility: no RegionPlan/MacroTerrainPlan API change; T9/G8 absence checks stay true. Values are Alpha constants; changing lattice step or gradient definition requires a `SCHEMA_TAG` bump.
