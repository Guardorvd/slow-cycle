## 3. Implemented domain contracts

The factual flow is:

```text
world_seed + Vector2i region_coordinate
    -> RegionIdentity
    -> RegionBounds
    -> MacroTerrainPlan(DEFERRED_R1)
    -> RegionPlan
```

**RegionSeedDerivation.** Stateless public `region_seed_preimage(world_seed, region_coordinate)` and `region_seed(world_seed, region_coordinate)` are total for the typed input domain. The only registered R0 purpose is `region_seed`. Preimage is ASCII-compatible UTF-8, ordered and LF-terminated:

```text
slow_cycle.seed/1
purpose=region_seed
count=3
v0=<signed decimal world_seed>
v1=<signed decimal coordinate.x>
v2=<signed decimal coordinate.y>
```

SHA-256 digest extraction starts with `digest[0] & 0x7F`, then folds bytes 1–7 using `(result << 8) | digest[i]`, yielding a nonnegative signed-int64 value in `[0, 2^63-1]` without unsigned overflow. There is no Godot `hash()`, RNG, time/allocation input or additive-offset derivation. The private `_preimage` helper does not enforce generic grammar/count bounds at runtime; see R1-NB4. R0's fixed purpose and fixed three inputs meet the approved framing contract.

**RegionIdentity.** Value-input construction stores world seed, a value-copy of the coordinate, and the derived region seed. Getter API exposes those values. `equals(other)` compares canonical world seed and coordinate; null is unequal. No mutable collection, registry or runtime state is exposed.

**RegionBounds.** Origin-aligned X/Z footprint in metres; coordinate.x maps to +X and coordinate.y to +Z. Minima are signed-int64 coordinate components times 4096; maxima are minima plus 4096. Full int32 extremes fit exactly in int64. `contains_world_xz(x, z)` accepts finite float64 values within half-open `[min_x,max_x) × [min_z,max_z)` bounds; NaN/Inf are rejected. No Vector2/Rect2 rounding, clamping, vertical extent, point-to-coordinate lookup or neighbour API is supplied.

**MacroTerrainPlan.** Schema state only: `get_state()` returns `DEFERRED_R1`. This carries no macro-terrain data, sampling function, geography or fallback.

**RegionPlan.** Constructs its own identity, bounds and macro state from value inputs; getter-only supported API. GDScript underscore privacy is conventional rather than runtime-enforced. `validate()` is diagnostic-only and returns `is_valid` with ordered `reason_codes`: `ERR_REGION_PART_MISSING`, `ERR_REGION_SEED_MISMATCH`, `ERR_REGION_BOUNDS_MISMATCH`, `ERR_MACRO_TERRAIN_STATE`. Valid construction produces an empty list. Some branches are structurally unreachable under supported R0 construction (R1-NB2).

Canonical text is ten ordered lines, including the terminal LF: schema tag `slow_cycle.region_plan/1`; `layout.region_size_m`; `identity.world_seed`; `identity.region_coordinate` as decimal `x,y`; `identity.region_seed`; `bounds.min_x_m`; `bounds.min_z_m`; `bounds.max_x_m`; `bounds.max_z_m`; `macro_terrain.state`. No dictionary or float enters this representation. `signature()` is SHA256 over canonical text. RegionPlan directly depends on RegionSeedDerivation for canonical identity/signature validation through its seed invariant; this benign one-way dependency is recorded in the as-is architecture note.

**RegionGenerator.** Static, stateless, total `build(world_seed, region_coordinate) -> RegionPlan`, independently constructing each caller-owned plan. R0 generates identity/bounds/schema data only. No Node/scene tree, renderer/physics ownership, shared mutable state, back-reference or production owner dependency is introduced.
