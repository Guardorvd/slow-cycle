# 🚲 Slow Cycle (Вело-дзен)

> *Медитативная поездка на велосипеде по бесконечному процедурному ландшафту.*  
> Вдохновлено философией игры **Slow Roads** (*anslo*).

---

## 🌟 Текущий статус проекта (Спринт 2C Завершён)
- **Спринт 1 (Физика и Кокпит)**: Кинематика велосипеда, камера 1-го/3-го лица, процедурное аудио (звонок и трещотка).
- **Спринт 2A (Бесконечная дорога)**: Детерминированная процедурная генерация по Seed, гравийный шейдер, полосовой террейн, MultiMesh леса, двухслойная физика, Recovery (`R`), Debug HUD (`F3`).
- **Спринт 2B (Soak Test)**: Пройден 52.5-км стресс-тест (3 сида × 17.5 км), стабилизация RAM на плато 46-47 MB, плотный руль с центробежным креном, Zero Pop-in в тумане.
- **Спринт 2C (Cleanup Gate)**: Нулевой техдолг — удалена рудиментарная передача `current_gear`, внедрён строгий assert на шум, растительность посажена точно по координатам $(X, Z)$, документация аудита актуализирована.
- **Следующий этап (Спринт 3A)**: Ключевой спринт — динамика велосипеда: lean-to-steer, калибровка наката, прогрессивное торможение, инерция педалей, cornering scrub.

## 🚀 Как запустить игру

1. Открой **Godot 4** со своего ярлыка на Рабочем столе.
2. Нажми **«Импорт» (Import)** $\rightarrow$ выбери папку проекта (содержащую файл `project.godot`).  
3. Нажми **«Импортировать и редактировать» (Import & Edit)**.
4. Нажми клавишу **F5** (или значок ▶️ Play в правом верхнем углу).

### Управление в игре:
- **`W` / `↑`** — Крутить педали (набор скорости).
- **Отпустить `W`** — Свободный накат под горку (разгон силой тяжести со стрёкотом трещотки).
- **`A` / `D` / `←` / `→`** — Руление с мягким наклоном байка в вираж.
- **`S` / `↓`** — Мягкий тормоз.
- **`Пробел`** — Велосипедный звоночек на руле 🔔.
- **`V`** — Переключить вид (1-е лицо от руля / 3-е лицо со спины).
- **`R`** — Мягкое возвращение на центр дороги с плавным затемнением экрана.
- **`F3`** — Включение / выключение оверлея телеметрии разработчика.
